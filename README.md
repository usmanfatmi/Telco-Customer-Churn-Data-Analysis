# Customer Churn Analysis Dashboard

## Project Overview

This project presents an interactive Customer Churn Analysis Dashboard built in Microsoft Excel using Power Query, Pivot Tables, Pivot Charts, KPI Cards, and Slicers. The objective is to analyze customer churn patterns, identify key factors influencing customer retention, and provide business insights through an easy-to-understand dashboard.

The dashboard uses the IBM Telco Customer Churn dataset and demonstrates the complete data analysis workflow, including data cleaning, transformation, analysis, and visualization.

## Dataset

**Dataset:** IBM Telco Customer Churn Dataset

The dataset contains customer demographic information, account details, subscribed services, payment methods, contract types, tenure, monthly charges, and customer churn status.

## Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards

## Data Cleaning

The dataset was cleaned using Power Query by performing the following steps:

* Removed unnecessary columns
* Corrected data types
* Replaced inconsistent values
* Removed blank and duplicate records
* Created Tenure Group categories
* Standardized categorical values
* Prepared the dataset for dashboard reporting.

## Dashboard Features

The dashboard includes:

* Total Customers KPI
* Churn Customers KPI
* Retained Customers KPI
* Churn Rate KPI
* Churn by Contract Type
* Churn by Internet Service
* Churn by Payment Method
* Churn by Tech Support
* Churn by Tenure Group

Interactive slicers are available for:

* Gender
* Contract
* Internet Service
* Payment Method
* Senior Citizen

## Key Insights

* Customers with Month-to-Month contracts have the highest churn.
* Fiber Optic customers show higher churn compared to DSL users.
* Electronic Check is the payment method associated with the highest churn.
* Customers without Tech Support are more likely to leave.
* Most churn occurs during the first year of customer tenure.
